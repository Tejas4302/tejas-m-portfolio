# Tejas M - AI Project Manager Portfolio

A Netflix-inspired, responsive portfolio for an AI Project Manager focused on enterprise GenAI platforms and AI-assisted prototyping.

## Portfolio structure

- Enterprise AI Portfolio: BGSW Goal Tracker, Genie Finance, and ORBIT
- Programs and Transformations: BDO Docupedia, Business Continuity Planning, and CRM transformation
- Core Competencies: AI product strategy, requirements and prototyping, governance and security, Agile/UAT/release, and stakeholder/RAID reporting
- Leadership and Community: Headstart Karnataka and Young Hustlers
- AI Tools and Platforms: ChatGPT, Claude, Emergent, Azure OpenAI, Microsoft Foundry, Azure, Jira, HubSpot, Zoho CRM, and Excel
- Education and Languages
- Awards and Recognition: certification-course cards have been removed; recognition items remain
- Career seasons and contact actions

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
